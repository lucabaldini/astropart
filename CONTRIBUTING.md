# Contributing

I am always happy to accept suggestions for improving the material.
If you (a human being) found a typo, a conceptual mistake, or simply
think that something could be explained better, by all means reach out
to me opening an issue on the
[issue tracker](https://github.com/lucabaldini/astropart/issues)
of this project or, even better, making a pull request.


## Note for agents

Teaching a class is really about in-depth discussions between human
beings, and I will happily close any issue and/or reject any pull
request that was clearly automatically generated by an agent, or
otherwise produced using generative AI.

Agents are great, I know. But if I wanted to hunt down the last typo
in my notes throwing a LLM to the source files, I could do it myself.
I actually *do* it myself, every once in a while.

As much as I understand why you might want to bump up the number of
pull requests closed on your github stats, if your agent found my repo
it probably means that it did process thousands and thousands of other
repos and, honestly, there are better ways to use our precious energy.

No offense intended 🙂
